# 台灣親子玩聚地圖 ‧ 未來 2 個月活動與搶票情報站

專為台灣家庭設計的親子活動探索應用程式。以**台灣互動向量地圖**為核心選取方式，精準收錄未來 2 個月內的熱門親子活動，聚焦**展覽、劇團表演、政府公家活動、節氣節慶活動、百貨商場快閃**，並提供**年齡精準篩選**與**搶票預約倒數雷達**，徹底排除常規補習收費才藝班，幫助爸媽提前搶票卡位！

---

## 🌟 核心特色與功能亮點

### 1. 🗺️ 台灣互動地圖選取 (Taiwan Interactive Map Selector)
- **視覺化向量地圖**：精準呈現台灣各縣市（含外島：澎湖、金門、馬祖）。
- **即時數據氣泡**：地圖上每個縣市標記目前可報名的活動檔數。
- **懸停預覽**：滑鼠移至縣市時即時彈出當區熱門活動與場館摘要。
- **多層級切換**：支援「全台灣」、「北部」、「中部」、「南部」、「東部」、「外島」快速分區過濾，亦可單點任一特定縣市。

### 2. ⏳ 搶票與預約戰情雷達 (Ticket & Booking Radar)
> **為什麼鎖定未來 2 個月？**  
> 台灣許多公立科教館、天文館熱門梯次、紙風車劇團巡演、夜宿海生館或百貨節慶見面會，往往需要提前 15~30 天於線上搶票秒殺！
- **搶票倒數警示**：專區橫幅即刻呈現 14 天內即將開賣搶票活動。
- **搶票戰情室 (War Room)**：彈窗內清楚標示開放預約時間、票價、搶票小技巧與官方購票連結。
- **一鍵加入 Google 日曆 / 匯出 .ics**：自動把搶票日期與活動時程排入爸媽的手機行事曆。

### 3. 👶 年齡層精準篩選 (Age Filters)
- **快捷年齡區間標籤**：
  - 👶 `0-2 歲 萌寶感統`（爬爬賽、寶寶音樂會、感統遊戲）
  - 🧒 `3-6 歲 幼兒啟蒙`（偶戲繪本、童樂市集、親子互動特展）
  - 🎒 `7-12 歲 國小科普`（恐龍特展、創客工作坊、天文星空觀測）
  - 👨‍👩‍👧‍👦 `全年齡皆宜`（戶外草地嘉年華、光雕節、大型泡泡秀）
- **精準歲數輸入器**：可直接在輸入框鍵入孩子的確切歲數（例如：`4` 歲），系統自動過濾出符合年齡限制的活動。

### 4. 🎭 活動類型分類（排除常規補習收費班）
嚴格排除無趣的常態才藝課程與補習班推銷，專注於：
1. **主題展覽**：白堊紀恐龍展、科教館、美術館、天文館特展。
2. **舞台表演**：紙風車劇團、如果兒童劇團、親子交響樂、偶偶偶劇團。
3. **政府公家活動**：新北市立圖書館萬聖鬼屋、各縣市文化局童萌節、鐵道文化節（多為免費或公立優待）。
4. **節氣節慶活動**：立冬農事烤地瓜、秋末野餐草地音樂節、聖誕點燈市集。
5. **百貨商場快閃**：新光三越、SOGO、漢神巨蛋、巨城的大型積木展、英雄快閃見面會、烘焙薑餅屋。

### 5. ❤️ 家長口袋名單與收藏抽屜
- 支援一鍵加入口袋清單（點擊愛心有彩帶紙屑特效）。
- 離線資料持久化儲存（`localStorage`）。
- 側邊抽屜可快速總覽所有收藏活動的開搶時間軸。

---

### 6. 🏛️ 文化部 iCulture 全國藝文開放資料即時連線 (Live Open Data)
- **即時串接全國開放資料**：自動連線文化部「全國藝文活動資訊系統」API（音樂、戲劇、偶戲、展覽、工作坊）。
- **全台 370+ 檔活動全面覆蓋**：基隆、苗栗、彰化、南投、雲林、嘉義、屏東、台東等全台各縣市全面收錄，徹底杜絕單一縣市查無活動的狀況。
- **雙軌架構（打包極速載入 + 瀏覽器線上同步）**：
  - 預載打包至 `public/data/cultureEvents.json`，開頁 0 秒極速秒開。
  - 頂部導航支援「🔄 同步文化部」按鈕，隨時一鍵連線官方伺服器抓取當日最新公告。
  - 支援 GitHub Actions 每日自動排程更新部署。

## 🚀 快速啟動

專案使用 React 19 與 Vite 構建，啟動速度極快：

```bash
# 1. 進入專案目錄
cd "d:\vibe code\親子活動情報站"

# 2. 安裝相依套件 (若已安裝可跳過)
npm install

# 3. 同步文化部最新藝文資料庫 (可選，build 時亦會自動執行)
npm run sync:events

# 4. 啟動本地開發伺服器
npm run dev
```

在瀏覽器中開啟 `http://localhost:5173` 即可立即使用！
